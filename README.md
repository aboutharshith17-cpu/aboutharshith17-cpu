## Featured Projects

### 🌿 Plant Disease Detection System

<p align="left">
  <img width="48%" src="https://github-readme-stats.vercel.app/api/pin/?username=aboutharshith17-cpu&repo=Plant-Disease-Detection&theme=nord&border_color=7dd3fc&title_color=7dd3fc" />
</p>

Plant disease detection system using EfficientNet, achieving **94% accuracy** across multiple crop and disease classes. Applies background removal, histogram equalization, and data augmentation for generalization, with FastAPI services integrated into a MERN Stack frontend for real-time diagnosis from leaf images.

| Layer | Technology |
|---|---|
| ML Model | TensorFlow (EfficientNet) |
| Image Processing | OpenCV |
| Backend | FastAPI |
| Frontend | MERN Stack (MongoDB, Express, React, Node.js) |
| Core | Python |

### 📚 EduBridge AI

<p align="left">
  <img width="48%" src="https://github-readme-stats.vercel.app/api/pin/?username=aboutharshith17-cpu&repo=EduBridge-AI&theme=nord&border_color=7dd3fc&title_color=7dd3fc" />
</p>

Full-stack platform for personalized student guidance and resource management. Integrates AI-powered career recommendations, scholarship matching, and internship tracking using LLMs/RAG over REST APIs, with JWT authentication, role-based access control, mentor-student networking, and real-time notifications. Ships a responsive, multilingual dashboard with analytics and progress tracking, deployed via Docker on AWS/Render.

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | FastAPI |
| AI | LLMs, RAG |
| Auth | JWT, Role-Based Access Control |
| Database | PostgreSQL, MongoDB |
| Deployment | Docker, AWS / Render |

🔗 [Code](https://github.com/aboutharshith17-cpu/EduBridge-AI.git)
